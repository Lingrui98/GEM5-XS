# Phase B-rev Step 1 F1 controller wiring

## Conclusion

Phase B-rev Step 1 is implemented and build/unit-smoke validated.

The SWAY controller now uses F1 miss/mispredict-rate utility for phase-boundary
transfer decisions. The old `active_ways / total_ways` utility remains in
`sway_phase_a_diag.csv` for audit.

## Code changes

- `DecoupledBPUWithBTB::SwayController` now maintains previous cumulative F1
  snapshots and computes per-phase deltas at each `chooseReallocation()` call.
- `SwayController::chooseReallocation()` compares:
  - donor pressure: MBTB F1 miss rate
  - donee pressure: aggregate TAGE F1 mispredict rate
- Configured TAGE donee table selection uses per-table F1 utility as the
  tie-break/selection signal, while the donate predicate uses aggregate TAGE
  utility as the component-level pressure signal.
- `sway_phase_a_diag.csv` is extended with:
  - `old_utility_mbtb`, `old_utility_ittage`, `old_utility_tage`
  - `new_utility_mbtb`, `new_utility_ittage`, `new_utility_tage`
  - `new_utility_tage_t0` ... `new_utility_tage_t7`
- Added narrow stat getters on MBTB, BTBTAGE, and BTBITTAGE instead of exposing
  private/protected stat groups to the top-level BPU.

## F1 formula implemented

- MBTB:
  `delta(predMiss) / (delta(predMiss) + delta(predHit))`
- TAGE aggregate:
  `delta(updateMispred) / max(1, delta(updateFilteredEntries))`
- TAGE table `t`:
  `delta(updateTableMispreds[t]) / max(1, delta(updateFilteredEntries))`
- ITTAGE audit:
  `delta(commitMisses) / (delta(commitMisses) + delta(commitHits))`

## Round 1 decision preservation checks

- D-1 alloc priority is still direction Y:
  `handleNewEntryAllocation()` scans native, borrowed, and extra storage inside
  the same invalid / weak-not-useful / not-useful priority levels.
- D-Return T2 cooldown-expiry re-evaluation remains present:
  `beginPhase()` marks newly expired donee cooldowns, and
  `chooseReallocation()` renews or returns an active MBTB tight donation at the
  expiry phase boundary.
- T3/T4 remain opt-in/not enabled in this Step 1 implementation.
